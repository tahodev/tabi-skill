# seoul-bike ガイド

ソウル市の公共自転車「タルンイ(따릉이)」のリアルタイム貸出台数をソウルオープンデータ広場APIで照会するスキル。サンプルキーで即動作確認できる(2026-09-14 サンプルキーで実データ取得を実測)。

**正本は [`seoul-bike/SKILL.md`](../../seoul-bike/SKILL.md)。** ページング、フィールドの読み方、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: ソウルオープンデータ広場 bikeList API(openapi.seoul.go.kr)
- できること: 「ホンデの駅近くでいま借りられる自転車はある?」にステーション名と台数で答える
- 注意: 照会のみ。実際のレンタルには公式アプリと決済登録が必要
