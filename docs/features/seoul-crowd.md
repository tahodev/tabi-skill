# seoul-crowd ガイド

ソウル市のリアルタイム都市データAPIで、明洞・弘大・光化門など主要スポットの現在の混雑度(4段階)を照会するスキル。サンプルキーで即動作確認できる(2026-09-14 実データ取得を実測)。

**正本は [`seoul-crowd/SKILL.md`](../../seoul-crowd/SKILL.md)。** フィールドの読み方、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: ソウルオープンデータ広場 citydata API(openapi.seoul.go.kr)
- できること: 「いま明洞は混んでる?」に混雑レベル(여유/보통/약간 붐빔/붐빔)で答える。同じ応答に天気・地下鉄・バス状況も入る
- 注意: サンプルキーは常に 광화문·덕수궁 のサンプルを返す。他の地点は実キーが必要
