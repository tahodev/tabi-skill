# korea-weather ガイド

韓国気象庁(KMA)の公共データ短期予報APIで、韓国各地の天気を取得するスキル。無料APIキーが必要(2026-09-09 オペレーション実在確認)。

**正本は [`korea-weather/SKILL.md`](../../korea-weather/SKILL.md)。** 格子座標、発表時刻、category早見、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: 기상청 단기예보(apis.data.go.kr/1360000)
- できること: 「明日のソウルの天気は?」に気温・降水確率つきで答える
- 注意: 予報は5km格子。発表時刻の10分後以降に照会
