# seoul-events ガイド

ソウル市の文化イベント情報APIで、コンサート・展示・祭りを月やジャンルで検索するスキル。サンプルキーで即動作確認できる(2026-09-14 サンプルキーで実データ取得を実測: 2026年10月フィルタで113件)。

**正本は [`seoul-events/SKILL.md`](../../seoul-events/SKILL.md)。** フィルタの構文、フィールドの読み方、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: ソウルオープンデータ広場 culturalEventInfo API(openapi.seoul.go.kr)
- できること: 「来月ソウルでやってる祭りある?」「週末の無料イベントは?」に答える
- 注意: ソウル市内のみ。全国の祭りは kto-tour(日本語対応)を使う
