# korea-tax-refund ガイド

韓国での買い物の税金還付(タックスリファンド)の静的データ。API不要・オフラインで使える。

**正本は [`korea-tax-refund/SKILL.md`](../../korea-tax-refund/SKILL.md)。** 対象条件、即時還付・事後還付の手順、仁川空港の還付場所はすべてそちら。このガイドは概要のみ。

- 収録: Duty Freeと事後免税の違い / 対象条件(1回15,000ウォン以上・未開封・3ヶ月以内に出国) / 即時還付(100万ウォン未満・総額500万ウォン以下) / 空港・市内カウンター還付(市内は600万ウォン以下の領収書のみ) / 仁川空港T1・T2の還付場所
- できること: 「いくらから還付される?」「空港でどこに行けばいい?」に即答する
- 出典・検証: 韓国観光公社「免税制度と税金還付」(最終更新2025-10-21)を2026-10-28に照合
- 注意: 金額条件は改正されうる。高額な買い物の前に1330または還付代行業者の公式案内で再確認を促す
