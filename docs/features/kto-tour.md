# kto-tour ガイド

韓国観光公社 TourAPI 4.0 の日本語サービス(JpnService2)で、観光地・祭り・宿・飲食店を日本語のまま検索するスキル。無料APIキーが必要(2026-09-09 6オペレーション実在確認)。このリポジトリの目玉。

**正本は [`kto-tour/SKILL.md`](../../kto-tour/SKILL.md)。** オペレーション一覧、地域コード・ジャンルコード、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: TourAPI 4.0 JpnService2(data.go.kr 15101578)
- できること: 「明洞の観光地は?」「9月の祭りは?」に日本語の名前・説明つきで答える
- 注意: 施設情報は登録データそのまま。営業時間は公式案内で再確認
