# japan-customs-allowance ガイド

韓国旅行から日本に帰国する際の税関の免税範囲の静的データ。API不要・オフラインで使える。

**正本は [`japan-customs-allowance/SKILL.md`](../../japan-customs-allowance/SKILL.md)。** 品目別の範囲、注意点はすべてそちら。このガイドは概要のみ。

- 収録: 酒類760ml×3本 / たばこ(紙巻200本・加熱式10個・葉巻50本) / その他20万円枠(1品目1万円以下は免税、1個20万円超は全額課税) / 20歳未満の酒・たばこ不可 / 別送品の合算
- できること: 「お土産はいくらまで免税?」に即答する
- 出典・検証: 税関「海外旅行者の免税範囲」を2026-10-28に照合(live-data-verified)
- 注意: 韓国のタックスリファンドとは別制度。改正されうるので公式案内での再確認を添える
