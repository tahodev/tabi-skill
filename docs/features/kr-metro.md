# kr-metro ガイド

国土交通部TAGOの地下鉄情報APIで、釜山・大邱・大田・光州など地方都市の地下鉄の駅検索と時刻表を照会するスキル。無料APIキーが必要(2026-09-14 オペレーション実在確認)。

**正本は [`kr-metro/SKILL.md`](../../kr-metro/SKILL.md)。** パラメータ、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: TAGO SubwayInfoService(openapi.tago.go.kr)
- できること: 「釜山で西面→海雲台の電車は?」に時刻表で答える
- 注意: リアルタイム到着ではなく時刻表。ソウルのリアルタイム情報は seoul-subway
