# incheon-airport ガイド

仁川国際空港の旅客便の到着・出発状況を、仁川国際空港公社APIで照会するスキル。無料APIキーが必要(2026-09-09 オペレーション実在確認)。

**正本は [`incheon-airport/SKILL.md`](../../incheon-airport/SKILL.md)。** 空港コード、項目の読み方、空港鉄道データ、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: B551177 StatusOfPassengerFlightsDSOdp / 空港鉄道は data.go.kr 15098226
- できること: 「成田からの便、遅れてる?」に変更後時刻・ゲート・ターミナルつきで答える
- 注意: 最終案内は航空会社・空港掲示で確認
