# korea-air-quality ガイド

韓国環境公団のエアコリア(AirKorea)大気汚染情報APIで、都市別のリアルタイムPM2.5/PM10/統合大気環境指数を照会するスキル。無料APIキーが必要(2026-09-14 オペレーション実在確認)。

**正本は [`korea-air-quality/SKILL.md`](../../korea-air-quality/SKILL.md)。** パラメータ、等級の読み方、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: 韓国環境公団 ArpltnInforInqireSvc(apis.data.go.kr/B552584)
- できること: 「今日ソウルの空気は?」にPM2.5/PM10の等級(좋음/보통/나쁨/매우나쁨)で答える
- 注意: リアルタイム測定のみ。明日以降の予報は別サービス。「나쁨」以上ならマスク(KF94)を勧める
