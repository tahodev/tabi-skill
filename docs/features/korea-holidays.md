# korea-holidays ガイド

韓国天文研究院(KASI)の特日情報APIで、韓国の祝日・国慶日・記念日を年月指定で照会するスキル。無料APIキーが必要(2026-09-14 オペレーション実在確認)。

**正本は [`korea-holidays/SKILL.md`](../../korea-holidays/SKILL.md)。** パラメータ、エラー時の対応はすべてそちら。このガイドは概要のみ。

- データ: KASI SpcdeInfoService(apis.data.go.kr/B090041)
- できること: 「秋夕(추석)っていつ?」「来月の旅行、祝日と重なる?」に正確な日付で答える
- 注意: 旧暦ベースの連休(설날・추석)は年ごとに変わる。推測で答えず必ずAPIで照会する
