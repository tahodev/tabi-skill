AIエージェントに。

KTX、ソウル地下鉄、為替、観光、仁川空港。
日本からの韓国旅行に必要な「調べもの」だけを集めた、AIエージェント向けオープンソースのスキルコレクションです。韓国観光公社の日本語APIをはじめ、公式APIと公開データだけを使います。MITライセンス。

INSTALL
# 全スキルをインストール
npx --yes skills add tahodev/tabi-skill --all -g
其の一 — ABOUT

tabi-skill とは

Claude Code、Codex、OpenCode など npx skills add に対応したコーディングエージェントに、韓国旅行の「調べもの力」を追加するスキル集です。姉妹レポに kurashi-skill(日本の暮らし)、baodao-skill(台湾の暮らし)。

公

公式データだけ

韓国観光公社TourAPI、国土交通部TAGO、ソウル市オープンデータ、気象庁。出所のはっきりした公式APIと公開データだけを使います。

鍵

無料キーまで

課金は一切不要。使うのは無料で即時発行できるAPIキーまで。スクレイピング対策の強いサービスは最初から対象外にしています。

読

照会と計算のみ

予約・購入・発券など状態を変える操作は扱いません。読み取り専用だから、安心してエージェントに任せられます。

其の二 — SKILLS

9つのスキル

各スキルの正本はリポジトリ内の <スキル名>/SKILL.md。ここではひとこと紹介だけ。全エンドポイントは公開日(2026-09-09)に実測検証済み。

為

krw-jpy-rate

Exchange rate

ウォン・円の為替レートを韓国輸出入銀行APIと韓国銀行ECOS APIの2ソースから取得。「1万ウォンは何円?」に答えます。

無料APIキーKEXIM / ECOS
駅

seoul-subway

Seoul subway

ソウル地下鉄のリアルタイム到着予測。「弘大入口から次の電車は?」に方面つきで。日本語駅名データつき。

無料APIキーソウル市
列

kr-train

KTX & trains

KTXなど列車の時刻・運賃を国土交通部TAGOの列車APIで照会。「ソウル→釜山、次は何時?」に。

無料APIキーTAGO
走

kr-bus

Express bus

高速バスの時刻・運賃をTAGO高速バスAPIで照会。深夜便の相談にも。

無料APIキーTAGO
天

korea-weather

Weather

韓国気象庁(KMA)の短期予報APIでソウル・釜山・済州の天気を取得。

無料APIキー気象庁
観

kto-tour

Tourism (日本語!)

韓国観光公社 TourAPI の日本語サービスで観光地・祭り・宿を検索。名前も説明も日本語で返ります。このレポの目玉。

無料APIキー韓国観光公社
空

incheon-airport

Incheon Airport

仁川空港の到着・出発便の遅延・ゲート・ターミナルを照会。空港鉄道(AREX)データつき。

無料APIキー空港公社
救

korea-emergency

Emergency

警察112・救急119・日本語対応1330・在韓日本国大使館。オフラインでも使える静的データ。

API不要静的データ
習

korea-etiquette

Basics

コンセント(C/F型)・チップ不要・T-money・交通マナーの実用チートシート。

API不要静的データ
其の三 — DEMO

エージェントに聞いてみる

インストールしたら、あとは自然に話しかけるだけ。スキルが質問に合わせて自動で選ばれます。

CONVERSATION EXAMPLE
明洞の近くでおすすめの観光地ある?
kto-tour
明洞エリアだと「南山ソウルタワー」「徳寿宮(トクスグン)」が近いです。徳寿宮は火曜〜日曜開館、月曜休み。
(出典: 韓国観光公社 TourAPI・日本語データ)
1万ウォンって今いくら? あとソウル→釜山のKTX、午後の便ある?
krw-jpy-rate
100円=871.54ウォンなので、1万ウォンは約1,147円です。(韓国銀行 2026-09-08)
kr-train
ソウル駅発・釜山行きKTXは午後も定期便があります。時刻と大人運賃をTAGOのデータでお出しします。
※ 表示はイメージです。実際の数値は時点と条件によって変わります。
